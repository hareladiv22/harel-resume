# קורות חיים אינטראקטיביים: הראל אדיב

אתר קורות חיים בסגנון "סטוריז": שקף אחד בכל מסך, מעבר בהקשה, בהחלקה או בחיצים.
HTML, CSS ו-JavaScript פשוטים, בלי ספריות. מתארח בחינם ב-Vercel.

## צפייה מקומית במחשב
1. ב-VS Code מתקינים את התוסף המומלץ **Live Server**.
2. קליק ימני על `public/index.html` → **Open with Live Server** (או **Go Live** בשורת הסטטוס למטה).
3. האתר נפתח בדפדפן ומתרענן לבד בכל שמירה.

> אל תפתחו את `index.html` בלחיצה כפולה. האתר טוען את הטקסטים מקובץ JSON, וזה עובד רק דרך שרת (Live Server או Vercel). בלחיצה כפולה יופיע רק דף הגיבוי הפשוט.

לינק לשקף מסוים: מוסיפים `#` ומספר השקף, למשל `https://harel-resume.vercel.app/?ref=linkedin#5`.

## עריכת טקסטים (מהדפדפן, בלי להתקין כלום)
כל הטקסטים נמצאים בקובץ אחד: `public/content.json`.

1. ב-GitHub נכנסים לריפו → `public` → `content.json` → אייקון העיפרון (Edit).
2. משנים **רק את הטקסט שבין המירכאות**.
3. כללים:
   - מירכאות כפולות ישרות `"` בלבד.
   - מירכאה בתוך טקסט נכתבת `\"`.
   - פסיק בין פריטים, ו**בלי** פסיק אחרי הפריט האחרון ברשימה.
   - `<em>…</em>` להדגשה (נטוי וצבעוני), `<br>` לשבירת שורה. שום תגית אחרת.
   - `true` / `false` ומספרים (כמו `"d": 8`) נכתבים בלי מירכאות.
4. למטה: **Commit changes** → בוחרים **Commit directly to the main branch** → **Commit changes**.
5. אחרי כדקה, ב-Vercel → הפרויקט → **Deployments** רואים את הפרסום:
   - **Ready** (ירוק): השינוי באוויר.
   - **Error** (אדום): משהו בקובץ שבור. **האתר הקודם נשאר באוויר**, אף מבקר לא רואה תקלה.
6. אם יש Error: לוחצים על הפרסום → **Building** / לוגים. ההודעה אומרת בדיוק איפה הבעיה, למשל:
   `slides[5].items[3].text: too long (130 > 120 characters)`
   - `slides[5]` = השקף השישי (הספירה מתחילה מ-0).
   - `items[3]` = הפריט הרביעי בשקף.
   - לשגיאת פסיק/מירכאה מופיע מספר שורה, ו-GitHub מציג מספרי שורות בצד.
   מתקנים באותה דרך (עיפרון → Commit), והפרסום הבא יעבור.
7. לחזור אחורה:
   - ב-GitHub → `content.json` → **History** → בוחרים גרסה קודמת ומעתיקים ממנה, **או**
   - ב-Vercel → **Deployments** → פרסום קודם שעבד → **⋯** → **Promote to Production** (מיידי).

### מגבלות אורך (כדי שהטקסט ייכנס במסך)
| שדה | מקסימום תווים |
|---|---|
| שורת פתיחה (`lines`) | 12 לכל שורה, 2–4 שורות |
| כותרת שקף (`h`) | 30 |
| כרטיס: `tag` / `title` / `text` / `big` | 28 / 40 / 120 / 12 |
| ציר זמן: `when` / `name` / `text` | 16 / 36 / 140 |
| מספרים: `l` / `s` | 50 / 45 |
| `sub` (פתיחה וסיום) | 90 |

תגיות `<em>` ו-`<br>` לא נספרות. הבדיקה האוטומטית תגיד אם עברת את המגבלה.

### שינוי שם, תפקיד, מייל, טלפון או לינקדאין
הפרטים האלה נמצאים בחלק `meta` בראש הקובץ. הם מופיעים גם בקובץ `public/index.html`, כי לינקדאין, וואטסאפ ומנועי חיפוש קוראים אותם משם, וגם דף הגיבוי מציג אותם. אם משנים אותם רק ב-`content.json`, הבדיקה תיכשל ותכתוב מה צריך לעדכן ב-`index.html`. הכי פשוט: לבקש מ-Claude לעשות את השינוי בשני הקבצים.

### החלפת קובץ קורות החיים
1. ב-GitHub → `public/assets/cv/` → **Add file** → **Upload files**.
2. מעלים קובץ **באותו שם בדיוק**: `Harel-Adiv-CV.pdf`. הוא מחליף את הישן.
3. **Commit changes**. אחרי הפרסום, רענון רגיל מציג את הקובץ החדש.

> כלל: כשמעדכנים את הקו"ח, מעדכנים את `content.json` באותו יום, ולהפך, כדי שהאתר והקובץ לא יסתרו זה את זה.

## בדיקה במחשב (אופציונלי)

שניהם משתמשים ב-Chrome שכבר מותקן במחשב. לא צריך להתקין שום חבילה.
